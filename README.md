# 🐾 Noche de Perros TV — Links Page

Página de redes sociales optimizada para móvil. Se accede desde un código QR.

## 🚀 Ver en vivo

Una vez activado GitHub Pages, la página estará en:  
`https://cookinglikedan-stack.github.io/Noche-de-Perros/`

## 📁 Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Página principal con todos los links |
| `Logo 1.png` | Logo oficial del canal |
| `Logo 2.png` | Logo alternativo |

## ✏️ Personalizar los links

Abre `index.html` y busca la sección `LINKS — EDITA LAS URLs` para cambiar:
- URLs reales de cada red social
- Tu número de WhatsApp
- Estadísticas reales del canal (función `count()` al final del script)

## ⚙️ Activar GitHub Pages

1. Ve a **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `(root)`
4. Guarda y espera ~1 minuto
